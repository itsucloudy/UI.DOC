How every file and layout layer is organized.

The project consists of five core files: index.html and styles.css at the root, plus mechanics.html, structure.html, and legals.html inside pages/. Every page shares the same structural skeleton and design tokens.

01 · Root Entry & Styles

index.html & styles.css

index.html serves as the locked home landing view, while styles.css centralizes all variables, layout rules, and @media queries for all four HTML pages.

02 · Subpages Directory

pages/ Documentation Trio

mechanics.html documents layout behavior, structure.html documents file hierarchy and CSS architecture, and legals.html documents scope, accessibility, and zero-dependency standards.

03 · Shared Page Skeleton

Header, Main & Footer

All four HTML files use identical .site-header and .site-footer landmarks wrapping either <main class="hero"> on the home page or <main class="page-content"> on subpages.

04 · Container Widths & Grid

1200px vs. 740px

.hero caps at 1200px on index.html so two columns fit side by side, while .page-content caps at 740px across mechanics.html, structure.html, and legals.html for comfortable reading.

Role of Each File in the Hierarchy

index.html: Uses body.stationary-viewport and main.hero to present the project overview, primary call-to-action buttons (.btn-mechanics and .btn-structure), and the interactive .hero-card summary link.

pages/mechanics.html: Uses body.subpage and main.page-content with five numbered .text-section blocks explaining viewport locking, active navigation states, card hover mechanics, relative paths, and mobile @media reflow across all files.

pages/structure.html: Pairs the four-card .structure-grid overview with .text-section breakdowns covering file roles, styles.css cascade order, and design tokens.

pages/legals.html: Uses the same body.subpage and .text-section pattern to define technical compliance, zero-dependency rules, and accessibility guarantees applied across all four pages.

CSS Cascade & Mobile Stack (@media)

styles.css is organized from top to bottom in four layers: :root color variables and the universal box-sizing: border-box reset, viewport mode classes (.stationary-viewport and .subpage), component styles (.site-header, .hero, .page-content, .structure-grid, and .site-footer), and finally the @media (max-width: 768px) block at the bottom.

Placing @media (max-width: 768px) at the end of styles.css ensures mobile overrides cleanly win the CSS cascade: unlocking .stationary-viewport on index.html, stacking .hero and .structure-grid via display: flex; flex-direction: column;, and centering .site-header and .site-footer across all four HTML documents.

Design Tokens & Typography

At the top of styles.css, :root stores shared CSS custom properties reused across every page: --bg (#f0eee6) for the page canvas, --surface (#faf9f6) for header, footer, and cards, --code-bg (#e7e3d8) for inline <code> tags, --text-main (#141413) and --text-muted (#5c5952) for readable hierarchy, --border and --border-subtle for dividers, and --accent (#cc785c) plus --accent-hover (#b56347) for interactive accents.

Across all pages, headings and .brand use Georgia, "Times New Roman", serif while body copy, navigation links, and buttons use system-ui, -apple-system, sans-serif.
