How the files and layout are organized.

The project is split into a root entry page, a shared stylesheet, and three subpages inside pages/. Instead of duplicating styles or writing separate CSS files per view, each page reuses the same classes and changes behavior through the body class.

01 · Root Directory

index.html & styles.css

index.html is the home page at the root of the project, and styles.css holds all CSS rules in one place. Every subpage links to ../styles.css so visual changes in one file update the whole site.

02 · Subpages Folder

pages/ Directory

mechanics.html, structure.html, and legals.html sit inside pages/. Each one uses the same <header class="site-header"> and <footer class="site-footer"> structure so navigation stays predictable across pages.

03 · Semantic Landmarks

Header, Nav, Main & Footer

Pages use semantic HTML elements—<header>, <nav>, <main>, <section>, <article>, and <footer>—to give the document clear regions for both human readers and assistive technologies like screen readers.

04 · Container Widths & Grid

1200px vs. 740px

.hero allows up to 1200px width so two columns fit comfortably side by side, while .page-content limits width to 740px for easier reading. Inside it, .structure-grid arranges cards in two equal columns with grid-template-columns: repeat(2, 1fr) and gap: 1.25rem.

Viewport Modes via Body Classes

The CSS file defines two main body classes: .stationary-viewport for index.html and .subpage for the secondary pages. .stationary-viewport sets height: 100dvh and overflow-y: hidden to lock the home screen to one screen height.

.subpage uses min-height: 100vh instead of a fixed height and removes overflow-y: hidden. Combined with flex: 1 on .page-content, the main area grows with its content and lets the page scroll normally while keeping the footer anchored at the bottom of the layout.

Design Tokens & Typography

At the top of styles.css, :root stores CSS custom properties (variables) so colors are defined once and reused everywhere: --bg (#f0eee6) for the outer background, --surface (#faf9f6) for header, footer, and cards, --code-bg (#e7e3d8) behind inline <code> tags, --text-main (#141413) and --text-muted (#5c5952) for text contrast, --border and --border-subtle for lines, and --accent (#cc785c) plus --accent-hover (#b56347) for highlights and hover states.

A universal reset at the top of styles.css sets box-sizing: border-box, padding: 0, and margin: 0 on all elements so borders and padding do not unexpectedly push elements wider than their containers. For fonts, headings use Georgia, "Times New Roman", serif while body copy and controls use system-ui, -apple-system, sans-serif.
