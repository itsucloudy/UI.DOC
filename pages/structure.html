How the files and layout are organized.

This project keeps a flat, predictable file tree and shares a single stylesheet across both the locked home viewport and scrollable subpages.

01 · Root Directory

index.html & styles.css

The entry point and global stylesheet sit at the root so every subpage can reference ../styles.css without duplicating rules.

02 · Subpages Folder

pages/ Directory

Houses mechanics.html, structure.html, and legals.html, keeping secondary views cleanly separated from the home screen.

03 · Semantic Landmarks

Header, Main & Footer

Every route uses <header>, <nav>, <main>, and <footer> rather than generic wrapper <div> tags.

04 · Container Widths

1200px vs. 740px

.hero spans 1200px for two columns, while .page-content narrows to 740px for comfortable line lengths.

Viewport Modes via Body Classes

Instead of maintaining two separate stylesheets, switching the <body> class changes how the page behaves. .stationary-viewport locks the home screen to 100dvh with hidden vertical overflow, whereas .subpage switches to min-height: 100vh so articles and grids scroll naturally.

Design Tokens & Typography

All colors live in :root custom properties—warm parchment surfaces (--bg and --surface), muted stone borders (--border), and terracotta accents (--accent). Headings use Georgia serif for editorial contrast against system-ui sans-serif body copy.
