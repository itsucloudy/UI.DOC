How the files, HTML landmarks, and stylesheet fit together.

The site runs on five files: index.html and styles.css in the root folder, plus mechanics.html, structure.html, and legals.html inside pages/. Every page pulls from that single stylesheet and follows the same top-to-bottom landmark skeleton.

01 · Root Folder

index.html and styles.css

index.html is the locked entry screen. styles.css holds every color variable, reset, layout rule, and @media override for all four pages.

02 · pages/ Folder

Three Documentation Subpages

mechanics.html breaks down layout and hover behavior, structure.html maps the file tree and stylesheet layers, and legals.html records the 65/35 authorship split and project scope.

03 · Semantic Landmarks

Header, Main, and Footer

Every HTML file wraps its content in <header class="site-header">, a <main> block (.hero on home or .page-content on subpages), and <footer class="site-footer">.

04 · Container Widths

1200px Home vs. 740px Docs

.hero widens up to 1200px so the intro column and clickable card fit side by side. .page-content stops at 740px so reading lines on the subpages never get too wide.

What Each File Does

index.html uses body.stationary-viewport and main.hero to lock the landing view to one screen. It holds the headline, short intro copy, two action links (.btn-mechanics and .btn-structure), and the clickable .hero-card.

pages/mechanics.html switches to body.subpage and main.page-content. It walks through how the two body modes, header bar, clickable card, CSS Grid, split bar, relative links, and mobile breakpoint behave in the browser.

pages/structure.html combines the four-card .structure-grid with .text-section blocks that document the directory layout, the order of rules in styles.css, and every custom property and font stack used across the site.

pages/legals.html reuses body.subpage and .text-section, adding the .split-card bar to document the 65% manual / 35% AI authorship split and the static HTML/CSS scope of the project.

How styles.css Is Ordered

styles.css flows top to bottom in four clear blocks. It opens with :root color variables and a universal * reset (box-sizing: border-box; padding: 0; margin: 0) so padding never adds unexpected width to containers. Next come the home page and shared chrome rules: .stationary-viewport, .site-header, .brand, .nav-container-row, .hero, the button and card styles, and .site-footer.

Below the footer, the stylesheet defines subpage components: .subpage, .page-content, .back-link, .page-title, .page-lead, .text-section (along with .page-lead code and .text-section code), the .split-card bar for legals.html, and .structure-grid for structure.html.

The @media (max-width: 768px) block sits at the very end. Because CSS applies later rules over earlier ones at equal specificity, placing the media query last lets mobile rules override desktop layout cleanly without reaching for !important.

Color Tokens and Font Stacks

:root defines 11 custom properties shared by every page. Surfaces use --bg (#f0eee6) for the canvas, --surface (#faf9f6) for the header, footer, cards, and secondary button, --code-bg (#e7e3d8) for inline <code> pills and the split-bar track, and --white (#ffffff) for text inside the solid accent button.

Text, borders, and interactive accents use --text-main (#141413), --text-muted (#5c5952), --border (#e2ddd2), --border-subtle (#d5cfc2), --bar-muted (#b8b1a3) for the AI bar segment, --accent (#cc785c), and --accent-hover (#b56347).

Typography relies strictly on system fonts with no external font downloads. Both body classes set system-ui, -apple-system, sans-serif for paragraphs, buttons, footers, and .hero-card h2. Display headings (.brand, .hero-headline, .page-title, .text-section h2, and .structure-card h3) switch to Georgia, "Times New Roman", serif. .site-header sets "Times New Roman", Times, serif, so the top navigation links inherit a serif face instead of the sans-serif body font.
