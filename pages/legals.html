How I built this site (and where AI helped).

This page lays out what I wrote by hand, where AI helped along the way, and what is actually running inside the project folder.

My Work · 65% AI Help · 35%

What I Built Myself (65%)

I started by looking at an early AI layout reference, then rebuilt the site myself by eye instead of copying generated code straight into the editor. I only checked back when I got stuck on a specific bug. I planned the four pages, set up the pages/ folder, and wrote the core rules in styles.css, including the 100dvh home viewport lock, Flexbox alignment, button and card styles, and the :root color variables.

I also tested every page in the browser, tracked down broken links and spacing issues, and decided to replace an earlier test form with this authorship and legals page.

Where AI Helped (35%)

AI generated the initial visual reference and helped speed up repetitive HTML tags, file naming, and early text drafts across the pages. It also helped catch relative path mistakes between the root folder and pages/ and build the markup for the .split-bar percentage bar above (a flex row holding 65% and 35% width segments inside a rounded container).

At the end of the project, AI helped polish and organize the site without rewriting the core code. That pass focused on aligning page explanations with the real CSS rules, cleaning up the wording and README.md, and adding a few small stylesheet tweaks (active-link highlighting, mobile footer stacking, and tighter mobile hero padding).

Technical Scope and Zero Dependencies

This is a static HTML5 and CSS3 school project built in GitHub Codespaces. There is no JavaScript, no external CSS library, no front-end framework, and no third-party font CDN. It does not connect to a backend server or database, and it loads no cookies, analytics, or tracking scripts. Every page opens directly in a browser as a plain local file.
