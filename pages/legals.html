How I built this project (and where AI helped).

Since this site documents how its own code works, it only makes sense to be upfront about how it was made. Here is an honest breakdown of what I wrote myself and what I handed off to AI.

My Work · 70% AI Help · 30%

What I Did (70%)

After seeing an initial AI prototype, I rebuilt the site from scratch by eyeballing the visual design rather than copying the original code—only checking back when I got genuinely stuck. I mapped out the multi-page structure and wrote the core CSS myself, including the locked 100dvh home screen, Flexbox alignment, card and button rules, and the pages/ folder setup.

I also tested everything in the browser, caught broken links and awkward line spacing, decided to replace my original test form with this legals page, and chose to organize the color palette with :root variables.

What AI Did (30%)

AI generated the initial visual prototype I used as a reference, and then acted as a helper for the repetitive HTML markup, file naming, and page copy. It helped catch relative path bugs between the root folder and pages/, structured the subpage sections, and wrote the text descriptions and percentage bar markup.

Project Scope

This is a plain HTML5 and CSS3 school project. There are no external frameworks, backend servers, databases, or tracking scripts—just static files built to demonstrate layout and styling fundamentals.
