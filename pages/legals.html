How I built this project (and where AI helped).

This page documents how the codebase was put together, what was written manually versus with AI assistance, and what technologies are actually inside the project.

My Work · 70% AI Help · 30%

What I Did (70%)

After looking at an initial AI layout reference, I rebuilt the site by looking at the design rather than copying the generated code directly, only checking back when I ran into a problem I could not solve on my own. I planned the pages and wrote the core rules in styles.css myself, including the 100dvh home viewport lock, Flexbox alignment, button and card styles, and the pages/ folder organization.

I also tested the pages in the browser, fixed broken links and spacing issues, chose to use this legals page instead of an earlier test form, and set up the color palette using :root custom properties.

What AI Did (30%)

AI generated the early visual reference and helped speed up repetitive HTML tags across the pages, file naming, and text drafts. It also helped spot relative path mistakes between the root folder and pages/, organize sections on the subpages, and write the markup for the .split-bar percentage bar above (which uses a flex row with 70% and 30% width segments).

Project Scope

This is a plain HTML5 and CSS3 school project. There are no JavaScript files, external CSS libraries, front-end frameworks, backend servers, databases, or analytics/tracking scripts—only static HTML and CSS files that open directly in a browser.
