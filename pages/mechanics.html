How every page and layout mode works.

This site is a multi-page static HTML and CSS project with no JavaScript. All four HTML files—index.html, mechanics.html, structure.html, and legals.html—are styled by styles.css, using Flexbox, CSS Grid, relative paths, and a single @media breakpoint to adapt across desktop and mobile screens.

1. Dual Body Modes: Home vs. Subpages

On index.html, the <body> uses .stationary-viewport, setting display: flex; flex-direction: column; height: 100dvh; overflow-y: hidden;. Using dynamic viewport height (100dvh) locks the home screen to the active visible browser height while .hero uses flex: 1 to center its content between .site-header and .site-footer.

On mechanics.html, structure.html, and legals.html, the <body> switches to .subpage, which replaces the fixed height with min-height: 100vh and removes overflow-y: hidden. Inside each subpage, .page-content uses flex: 1 so long articles scroll naturally while keeping .site-footer anchored at the bottom even on shorter pages like legals.html.

2. Shared Navigation & Active Link State

Every file renders the same .site-header Flexbox bar with justify-content: space-between, placing .brand on the left and .nav-container-row ul on the right with gap: 1.5rem.

On the three subpages inside pages/, the active link sets aria-current="page" in HTML, which styles.css highlights in var(--accent)—giving users clear location feedback without JavaScript routing.

3. Hero Split, Grid Cards & Interactive Hover States

On index.html, .hero pairs .hero-content and .hero-card side by side inside a 1200px container. Writing .hero-card as a block-level <a> tag makes the entire card clickable, lifting 4px via transform: translateY(-4px) on hover, while .btn-mechanics and .btn-structure provide direct action links.

On structure.html, .structure-grid uses CSS Grid (grid-template-columns: repeat(2, 1fr), gap: 1.25rem) inside a 740px reading column to arrange four architectural overview cards in balanced pairs.

4. Relative Folder Paths Across Root & Subpages

Because index.html and styles.css sit at the root while mechanics.html, structure.html, and legals.html sit inside pages/, links adjust by directory depth. From index.html, links point downward using pages/mechanics.html, pages/structure.html, and pages/legals.html.

From any file inside pages/, ../ steps up one folder to reach ../index.html and ../styles.css, while sibling subpage links use direct filenames like mechanics.html, structure.html, or legals.html.

5. Site-Wide Mobile Reflow (@media)

All four HTML files declare <meta name="viewport" content="width=device-width, initial-scale=1.0" /> so mobile browsers render at true device width. When the viewport hits @media (max-width: 768px), styles.css updates every page simultaneously:

On index.html, .stationary-viewport unlocks to height: auto and overflow-y: visible, while .hero switches to flex-direction: column. On structure.html, .structure-grid switches from a 2-column grid to display: flex; flex-direction: column;. Across all four pages, .site-header and .site-footer stack vertically and center their items so navigation never crowds on narrow screens.
