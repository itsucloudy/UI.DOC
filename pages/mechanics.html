How the layout and navigation work.

This site is a multi-page static HTML and CSS project with no JavaScript. Each page is a separate HTML file styled by one shared stylesheet, using Flexbox, CSS Grid, and relative file paths to control layout and navigation.

1. Stationary Viewport Lock (Home)

On index.html, the <body> element has the class .stationary-viewport, which sets display: flex; flex-direction: column; height: 100dvh; overflow-y: hidden;. This forces the home page to match the exact height of the browser window and hides vertical scrollbars so nothing spills past the screen edge.

100dvh stands for dynamic viewport height. Unlike 100vh, which can be taller than the visible screen on mobile phones when the address bar or bottom toolbar is shown, 100dvh adjusts to the active visible height.

Because .stationary-viewport is a vertical flex column, .site-header sits at the top, .site-footer sits at the bottom, and .hero uses flex: 1 to stretch and fill whatever vertical space is left between them, centering its contents with align-items: center.

2. Two-Column Hero & Full-Card Anchor Links

Inside .hero, display: flex, justify-content: space-between, and gap: 3rem place .hero-content (the headline, subtext, and action buttons) on the left and .hero-card on the right. The container caps at max-width: 1200px and centers horizontally with margin: 0 auto.

.hero-card is written as an <a> tag rather than a <div> containing a small link, and its CSS sets display: block, color: inherit, and text-decoration: none. That makes the entire card box clickable instead of just the Explore How It Works → label.

Hovering over .hero-card changes its border color to var(--accent) and moves it up by 4px using transform: translateY(-4px) over 0.15s. The two buttons next to the hero text (.btn-mechanics and .btn-structure) are styled <a> links with 10px rounded corners—one filled with the terracotta accent color and the other using a light surface background and subtle border.

3. Relative Folder Paths & Multi-Page Linking

index.html and styles.css live in the root folder, while mechanics.html, structure.html, and legals.html live inside the pages/ subfolder. Because of that folder split, links in index.html point to pages/mechanics.html, pages/structure.html, and pages/legals.html.

Inside any file inside pages/, ../ moves one level up from pages/ back to the root folder. That is why every subpage uses href="../index.html" for the brand link and back link, and href="../styles.css" to load the stylesheet, while links between subpages use direct filenames like structure.html or legals.html.
