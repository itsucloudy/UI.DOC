How the layout and navigation work.

Unlike the stationary home screen, this page removes the strict viewport height lock so longer technical explanations can scroll naturally without clipping content.

1. Stationary Viewport Lock (Home)

The home page uses .stationary-viewport with display: flex; flex-direction: column;, height: 100dvh;, and overflow-y: hidden;. Using 100dvh (dynamic viewport height) helps fit the screen cleanly even when mobile browser address bars appear or hide.

Inside that vertical flex column, the header stays at the top, the footer stays at the bottom, and .hero expands with flex: 1 so its content centers vertically in the remaining space.

2. Two-Column Hero & Full-Card Anchor Links

On the home screen, .hero uses Flexbox with justify-content: space-between and align-items: center to place .hero-content on the left and .hero-card on the right inside a max-width: 1200px container.

Instead of making only a small text link clickable, <a class="hero-card"> is set to display: block so the entire card surface acts as a single link with hover border feedback.

3. Relative Folder Paths & Multi-Page Linking

Because index.html sits in the root folder while mechanics.html, structure.html, and legals.html live inside pages/, links from the home page point to pages/... while links inside subpages use ../ to step back up to the root folder.

Likewise, each subpage loads the shared stylesheet with ../styles.css so visual styling—warm parchment surfaces, terracotta accents, serif headings, and sans-serif body text—stays consistent across every route.
