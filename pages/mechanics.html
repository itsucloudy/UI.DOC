How the layout, links, and CSS rules work.

There is no JavaScript anywhere in this project. All four HTML files share one stylesheet (styles.css), so every layout mode, hover state, and mobile adjustment comes straight from HTML structure and CSS rules.

1. Two Body Modes: Locked Home vs. Scrollable Subpages

On index.html, the <body> uses .stationary-viewport. That class sets display: flex; flex-direction: column; height: 100dvh; overflow-y: hidden;. Using 100dvh (dynamic viewport height) matches the visible browser height instead of getting trapped behind mobile toolbars. Inside that column, .hero gets flex: 1 so it fills the space between .site-header and .site-footer and centers its children vertically with align-items: center.

Subpages switch the body class to .subpage. Instead of locking the height, .subpage sets min-height: 100vh and leaves vertical scrolling open. .page-content also uses flex: 1, so long pages scroll normally while shorter pages still push .site-footer down to the bottom of the screen.

2. Header Bar, Navigation Links, and aria-current

Every page renders the same .site-header bar. It uses Flexbox with justify-content: space-between and align-items: center to place .brand on the left and .nav-container-row on the right. Inside the nav, .nav-container-row ul strips list bullets with list-style: none and spaces the links horizontally using gap: 2rem.

Nav links start in var(--text-muted) and turn var(--accent) on :hover. Each subpage also adds aria-current="page" to its own nav link. styles.css targets .nav-container-row a[aria-current="page"] with color: var(--accent) and font-weight: 600, so the active page stands out both visually and for screen readers with no JavaScript routing.

3. Hero Split, Action Buttons, and the Clickable Card

On index.html, .hero caps at max-width: 1200px, centers itself with margin: 0 auto, and separates .hero-content from .hero-card with gap: 3rem. Below the intro text, .hero-actions places two buttons side by side with gap: 1rem. .btn-mechanics uses a solid var(--accent) fill that darkens to var(--accent-hover) on hover. .btn-structure uses var(--surface) with a var(--border-subtle) border that switches to var(--accent) on hover.

.hero-card is an <a> element styled with display: block and color: inherit, rather than a plain <div> with a small link tucked inside. That makes the entire 420px card clickable. On hover, border-color shifts to var(--accent) and transform: translateY(-4px) nudges the card up over 0.15s.

4. Grid Cards and the Pure-CSS Split Bar

On structure.html, .structure-grid uses CSS Grid with grid-template-columns: repeat(2, 1fr) and gap: 1.25rem inside the 740px .page-content container. That splits the four .structure-card blocks into two even rows on desktop.

On legals.html, .split-card draws the 65/35 authorship bar with plain HTML and CSS. .split-bar is a 12px-tall flex row with border-radius: 999px and overflow: hidden so the inner fills stay rounded at both ends. Inside it, .split-fill-human takes width: 65% in var(--accent) and .split-fill-ai takes width: 35% in var(--bar-muted). Adding role="img" and an aria-label lets screen readers announce the ratio.

5. Relative Paths Between Root and pages/

index.html and styles.css live in the root folder, while mechanics.html, structure.html, and legals.html sit one level down in pages/. Because of that folder layout, index.html loads styles.css directly and links downward using pages/mechanics.html, pages/structure.html, and pages/legals.html.

Any file inside pages/ uses ../ to step up one directory to reach ../styles.css and ../index.html. Links between the three subpages stay in the same directory, so they only need bare filenames like mechanics.html, structure.html, and legals.html.

6. Mobile Reflow Under 768px

All four HTML files include <meta name="viewport" content="width=device-width, initial-scale=1.0" /> so phones render at real screen width instead of shrinking a desktop page. When the viewport reaches @media (max-width: 768px) at the bottom of styles.css, several layout rules switch at once.

On index.html, .stationary-viewport drops its fixed height (height: auto; overflow-y: visible) so nothing gets clipped, and .hero stacks vertically with flex-direction: column and tighter side padding (2rem 1.25rem). Across every page, .site-header and .site-footer stack and center their items, while .nav-container-row ul turns on flex-wrap: wrap so links wrap instead of overflowing sideways. On structure.html, .structure-grid switches from a 2-column grid to display: flex; flex-direction: column.
